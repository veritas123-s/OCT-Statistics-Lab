# OCT 统计画布

一个类似 Desmos 的可操作统计演示界面。左侧为可编辑教学数据与统计量，中间为可拖动、缩放和平移的散点画布；具体数值推导按需展开。

## 使用

- 修改 X、Y 单元格，或在原始 / 中心化坐标中拖动参照点，实时观察均值、方差、协方差矩阵、特征向量和距离变化。
- 在原始、中心化、主轴、白化坐标之间切换；独立显示均值中心、特征向量、马氏等距椭圆与待测点。
- 展开原始数据 / 元数据表，查看完整附件的 **149 条记录、25 个字段**，从中选择待测点或加入参照。
- 每项“计算”展示当前数据下的逐项数值，包括离差、离差平方、离差乘积、特征分解、投影、白化以及两种马氏距离算法。
- 可以新增教学观测、修改待测点和导出当前数据。原始附件和元数据始终保留原值。

直接打开 `docs/index.html` 可离线使用，无需安装依赖。访问论文链接需要网络。GitHub Pages 从 `main` 分支的 `/docs` 发布。

## 数据来源

Laible M, Jarius S, Mackensen F, et al. **Adding Papillomacular Bundle Measurements to Standard Optical Coherence Tomography Does Not Increase Sensitivity to Detect Prior Optic Neuritis in Patients with Multiple Sclerosis.** *PLOS ONE*. 2016;11(5):e0155322.

- 原文及附件入口：[DOI: 10.1371/journal.pone.0155322](https://doi.org/10.1371/journal.pone.0155322)
- 原始附件：S1 Dataset，XLSX，工作表 `Daten_für_PLOS`。本仓库 `docs/source-data.xlsx` 保持下载内容不变。
- 原始 XLSX 的 SHA-256：`88970e728ea9893340dd53e3faf6366c1c0cd06ca24be5833802abca42a7490e`。
- X 为原表 K 列的 N-RNFL 全局厚度（原始表头为 `Mean_NRFNL_overall (µm)`）；Y 为 L 列 `Mean_NRNFL_PMB`，单位均为 μm。
- 默认参照取 Patient-1 至 Patient-5 的右眼，原表第 2、4、6、8、10 行。原始值依次为 `(84,33), (71,28), (86,52), (105,63), (90,43)`。
- 默认比较点为 Patient-6 右眼 `(88,69)`、Patient-8 右眼 `(115,63)`，分别在原表第 13、16 行，没有参与默认参照统计量的估计。
- 原始文章按其 Creative Commons Attribution 开放许可使用与署名。原始数据遵循原文及其附件的许可；本仓库不将教学修改说成论文观测。

## 解释范围

默认 5 个样本仅用于数值教学，包含不同既往视神经炎史，不能构成健康参考范围。PMB 与全局 RNFL 存在整体与局部的关系；相关不等于因果，零协方差不保证独立。马氏距离等值线没有自动的概率或置信水平含义。对同一受试者双眼进行推断时需要处理眼间相关。

协方差矩阵不可逆或数值上接近奇异时，界面明确显示普通马氏距离不可计算，并禁用白化坐标，不自动添加正则化或将缺失值当作 0。

## 校验

无需安装第三方依赖：

```sh
node verify-lab.cjs
```

验证原始数据、统计数值、特征分解、白化协方差、马氏距离、平移及可逆缩放下的距离不变性，以及奇异矩阵和非法输入。

网页由原生 HTML / CSS / JavaScript 与 SVG 构成，运行中不发送数据请求，不保存账号凭据。
