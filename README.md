# OCT 统计画布与可回退矩阵实验

类似 Desmos 的可操作统计界面。默认打开矩阵实验；左侧可改教学数据、展开逐项计算，右侧手动控制中心化、旋转和缩放，可撤销、重做或拖回任意状态。

## 使用

- 点击原始观测、中心化、旋转对齐、白化缩放，查看对应状态；每个滑块都直接决定当前状态，不自动播放。
- 平移、旋转、缩放矩阵与累计矩阵并列显示；选一个点，展开每一步乘法、当前坐标和逆变换恢复数值。
- 显示协方差传播 S′=MSMᵀ、随变换一起变形的网格、基向量和椭圆。
- 矩阵缩放改变数据，适应图形及镜头缩放只改变视图；两者独立。白化后可点击适应图形放大查看。
- 返回散点编辑后可拖动参照点和待测点、切换坐标与图层。左侧也可以直接编辑、新增或移除观测，导出当前教学副本。
- 元数据表保留原始附件全部 3,022 条记录、80 个字段，按50行分页，支持查看临床字段或全部字段、选为待测点或加入参照。

直接打开 docs/index.html 可离线使用。GitHub Pages 从 main 分支 /docs 发布。运行时没有网络数据请求，不保存账户或凭据。

## 矩阵与数值

列向量按 p′=D R (p−t p̄) 变换。平移T为3×3齐次矩阵，R为2×2旋转矩阵，D为2×2轴向缩放矩阵；累计H=D₃R₃T。平移不改变协方差，S′=(DR)S(DR)ᵀ。

旋转基采用Q₊=[q₁,−q₂]，det(Q₊)=+1；相对于统计面板的第二主轴只差符号，距离不变。原统计基det(Q)=−1，不能将它直接当作纯旋转而忽略反射。

默认均值(88.2,63.94491935780616)，协方差矩阵[[229.7,162.886242313261],[162.886242313261,176.5865616640359]]，特征值368.1802078147434、38.106353849292546。白化旋转角为−40.3700297771°，缩放为各特征值平方根的倒数。

## Manim 与复现

使用 Manim Community 0.22.1 的Circle、VMobject贝塞尔控制点和apply_matrix生成几何，实际验证平移、旋转、缩放及逆变换。网页实时对这些Manim控制点应用同一矩阵；没有预渲染视频、自动播放或用离散截图替代连续交互，也不声称浏览器运行Python。

```sh
python -m pip install -r manim/requirements.txt
python manim/generate_geometry.py
node verify-lab.cjs
```

生成docs/manim-geometry.js。生成几何不需要LaTeX或视频渲染。

校验覆盖原始记录、分组/访次/眼别选择、均值协方差、特征分解、白化、任意中间矩阵的正逆变换、协方差传播、距离不变性、Manim几何与奇异输入。基准值由NumPy独立核验。

## 解释范围

5条默认观测用于数值教学，不复现原文的纵向混合模型，也不是临床参考范围。重复访次或双眼用于推断需处理相关性。相关不等于因果，零协方差不保证独立，等距椭圆没有自动的置信水平含义。奇异协方差不计算普通马氏距离，不将缺失值当作0。原始观测保持完整精度，界面显示时四舍五入。
